# 简历编辑器

纯静态网页，无需后端或构建。将本目录的 `index.html`、`.nojekyll` 和 `assets` 文件夹一起放到 GitHub Pages 的发布目录即可。此文件夹不包含私人简历。

## 使用

- 首页选择本地 `.resume.json` 项目文件，或选择模板后输入姓名。
- 浏览器会自动保存。首页「打开现有简历」也可打开本机已保存的简历。
- 「保存项目文件」下载 `.resume.json`，包含经历库、各版本、课程与照片。换电脑、浏览器或网址时，通过这个文件迁移；首页的打开入口只读取本地文件，不读取网页上的项目列表。
- 修改经历只影响当前版本。点击顶部「同步修改至经历库」并确认，才更新底稿；「恢复经历库内容」恢复最新底稿，不改变勾选、排序与排版。
- 「成绩库」只维护课程名称、成绩和单门课程的成绩显示；不再提供课程勾选。模块编辑器支持删除整个模块及其中经历，删除后可以撤销。
- 「导出」可生成独立 HTML、PNG 长图，或调用浏览器打印保存 PDF。打印时关闭页眉页脚、使用 100% 缩放；选择与编辑器一致的纸张尺寸。

## 隐私与保存

内容仅保存在浏览器与用户下载的项目文件中，不上传至服务器。浏览器缓存可能被清除，请定期保存项目文件。GitHub Pages 与原本地 HTML 使用不同的存储空间，发布后第一次使用需要导入项目文件。

不要将私人 `.resume.json`、含个人信息的导出 HTML/PDF、工作目录或整个 `outputs` 文件夹一起上传。只发布本 `site` 目录。
