# ResuWeave

ResuWeave 是一个简历工作台。你可以在这里集中整理自己的教育、实习、项目、比赛和技能经历，根据不同申请场景创建多个简历版本，并导出最终简历文件。

当你的经历越来越多时，你通常需要面向不同岗位调整简历内容。ResuWeave 希望把这个过程变得更简单：你只需要长期维护一份完整的经历底稿，再根据不同目标选择、组合和调整其中的内容。

---

## 1. 开始使用

你可以通过三种方式进入 ResuWeave，选择最适合当前情况的一种即可。

### 1.1 打开现有项目

如果你之前已经使用过 ResuWeave，可以直接导入保存的 `.resume.json` 项目文件。

项目文件会保存之后仍然可以继续编辑的数据，包括经历、简历版本以及相关设置。重新导入以后，你可以继续维护经历库、调整不同版本并再次导出。你也可以通过这种方式在不同浏览器或设备之间迁移项目，并将项目文件作为长期备份保存。

### 1.2 从模板开始

如果你是第一次使用，也可以直接从现有模板创建项目。

模板会提供一份已经建立基本结构的简历。你可以在此基础上替换个人信息、修改经历内容、调整模块，并继续选择不同样式。这种方式适合希望快速完成第一份简历的情况。

### 1.3 使用自己的 AI 创建项目

如果你已经拥有旧简历、个人经历介绍、项目材料或其他文字信息，也可以让自己常用的 AI 帮你完成第一次数据整理。

ResuWeave 可以提供 **Sample JSON、项目结构说明和 Prompt**。你可以将这些内容和自己的个人信息一起交给 ChatGPT、Claude、Gemini 或其他能够生成结构化 JSON 的 AI 工具。AI 根据指定结构整理完成后，会生成一个项目文件。将这个文件导入 ResuWeave，就可以直接进入可视化编辑器继续修改。

---

## 2. 经历库与多版本简历

ResuWeave 会分别管理你的完整经历和不同简历版本。

经历库适合保存相对完整的个人背景。例如一段实习经历可以保留更多项目细节、工作内容和成果，不需要因为当前简历只有一页就提前删减。制作某个具体简历版本时，你可以再根据目标岗位选择其中最相关的经历。

不同版本可以使用同一个经历库，同时保持各自独立的内容选择、顺序和布局。随着申请方向变化，你可以继续创建新的版本，而原有经历仍然保留在统一的底稿中。

---

## 3. 编辑与预览

进入编辑器后，你可以继续修改基础信息、经历内容以及当前简历版本的结构。不同内容模块可以根据申请场景进行选择和排序，也可以切换模板、照片以及其他展示设置。编辑结果会同步反映在简历预览区域，因此你可以一边修改内容，一边观察最终版面的变化。

---

## 4. 项目文件

`.resume.json` 是 ResuWeave 用来保存完整项目数据的文件格式。

最终导出的 PDF、PNG 或 HTML 更适合投递和分享，而 `.resume.json` 可以用于继续编辑和恢复项目，项目文件中保存着你的经历库、简历版本以及相关配置。

因此你可以在完成重要修改后导出一份项目文件作为备份，如果之后更换设备或浏览器，也可以重新导入这个文件继续编辑。

---

## 5. Local-first

ResuWeave 采用本地编辑的方式。你的简历通常包含姓名、联系方式、教育背景、实习经历等个人信息，核心编辑流程在本地完成。你不需要注册账号，也不需要依赖远程服务器才能创建和管理简历，`.resume.json` 项目文件可以由你自己保存、迁移和备份。

如果你使用 AI 辅助初始化，也可以自行决定向 AI 服务提供哪些信息。

---

## 6. 导出

完成编辑后，你可以将当前简历输出为不同格式。HTML 适合保留网页形式的展示结果，PNG 适合快速预览和分享，正式投递时则可以通过浏览器打印功能保存为 PDF。即使最终简历已经导出，也建议同时保留对应的项目文件，方便之后继续修改。

---
